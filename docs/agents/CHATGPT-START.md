# Study handoff without repository tools

Export a fresh study packet using the command in [agent setup](README.md). Attach it and say:

> Follow the attached learning guidance. State the current recorded evidence and one session objective. Ask one question at a time, wait for my attempt, and keep assistance distinct from mastery. Give me a dated proposed learner-log update based only on work I actually submit.

For an unaided assessment, ask for the task and conditions first, then submit your work with start/finish times and any assistance. Feedback comes afterward.

The packet includes README, teaching notes, discussion prompts, problems/exercises when present, and current learner work/reflection. It excludes separate solution/answer files and strips folded answer keys; lesson notes can still contain worked examples. It is study context, not a closed-book assessment packet. Review content before using it for an assessment.

A chat without file tools cannot save progress or open local links. Supply missing source passages and save proposed updates yourself. A local path in a packet does not provide access to that file. Do not accept completion changes until the shared evidence gate is met.
