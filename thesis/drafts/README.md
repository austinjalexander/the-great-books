# Thesis — Drafts

One file per major draft. Never overwrite. Typical sequence:

- `draft-1.md` — Senior fall full first draft.
- `draft-2.md` — Senior spring revision, full pass.
- `draft-3.md` — Senior spring second revision, full pass.
- `draft-final.md` — submitted for defense.

Each draft starts with a short header dating it and naming the changes from the previous draft. Major revisions are always full passes — nothing is "just fixing a paragraph."

Use [`../../.agents/skills/grade-composition/SKILL.md`](../../.agents/skills/grade-composition/SKILL.md) to review each draft on the rubric before advancing to the next.
