# Thesis — Working notes

Organize by primary source. One file per major source, e.g. `aristotle-metaphysics.md`, `aquinas-on-being-and-essence.md`. Each file collects passages, one-sentence paraphrases, and marginal comments keyed to the thesis outline.

Append as you read. Do not overwrite. Cross-reference back to the `outline.md` section each note is for.
