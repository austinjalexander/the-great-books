# 3-Natural-Science — The New Science

Descartes's programmatic *Principles of Philosophy*; Galileo's *Two New Sciences*; Newton's *Principia* read for the first time. This is where TAC asks the student to confront the break with Aristotelian natural philosophy and ask what, if anything, the old framework preserved.

**Syllabus citation** (Junior, Natural Sciences): Descartes — *Principles of Philosophy*; Galileo — *Two New Sciences*; Newton — *Mathematical Principles of Natural Philosophy* (*Principia*).

**Primary editions**: Cottingham-Stoothoff-Murdoch for Descartes; Drake (Wall & Emerson) for Galileo; Cohen-Whitman (California) for Newton. See [`RESOURCES.md`](../../../RESOURCES.md#galileo-newton-kepler-descartes-geometry-huygens-faraday-maxwell-einstein).

## Reading order

1. `01-descartes-principles-of-philosophy/`
2. `02-galileo-two-new-sciences/`
3. `03-newton-principia-junior/` — first pass: Definitions, Laws, Book I Sections I–III, Book III System of the World (selections). The Senior Natural Science module returns to *Principia* with more machinery.

## Companion readings across the program

- 2-Mathematics — Ptolemy, Copernicus, Kepler set up the astronomical problem Newton solves.
- 2-Philosophy — Aristotle *Physics* is the background Galileo and Newton are arguing with.
- 3-Mathematics — Viète, Descartes's *Geometry*, Archimedes's *Quadrature* supply the mathematical machinery.
- 4-Natural-Science — Newton's *Opticks* and *Principia* revisit; Huygens, Gilbert, Faraday, Maxwell.
