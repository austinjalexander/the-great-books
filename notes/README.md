# notes

One folder per year, one subfolder per subject track, one module per work (or tightly linked cluster of works). The canonical blueprint is [`../docs/CURRICULUM.md`](../docs/CURRICULUM.md); this tree is its physical instantiation.

## Layout

```
notes/
  year-1-freshman/
  year-2-sophomore/
  year-3-junior/
  year-4-senior/
```

Each year folder contains a `README.md` (year-level overview and subject links) and one subfolder per subject, numbered to match its position in `CURRICULUM.md`. A subject folder contains numbered work-modules; a work-module is four files for humanities works, six for mathematics / natural-science works, and five for Latin.

The reference implementation — the module to imitate — is [`year-1-freshman/4-mathematics-euclid/01-euclid-elements-book-1/`](year-1-freshman/4-mathematics-euclid/01-euclid-elements-book-1/). Read it before starting any other module.
