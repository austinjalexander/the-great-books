# Conduct a learning session

Read `AGENTS.md`, `docs/agents/PROFILE.md`, `docs/agents/tutoring.md`, `PROGRESS.md`, the module README/notes/prompts, and the latest learner log/reflection. Keep solutions closed during first attempts. Use `author-module` for missing materials and the appropriate grading skill for submitted work.

1. Name the curriculum section and module path; choose one observable session objective within the learner's available time. State a modest proposed scope if no duration is known.
2. Locate the starting point from actual evidence and one short opening question. Distinguish essential prerequisites from useful companions and later readings. Use `diagnose-prereqs` only when meaningful gaps need routing; do not quiz on nonexistent prerequisites.
3. Assign a short passage, then wait for the learner's reading/attempt. Ask one question at a time. Reading silently is sufficient. Require standard passage references for interpretations and reasons for proof steps.
4. Work through a claim, demonstration, or parsing task with staged hints. For discussion, develop an objection, a passage-supported reply, and the learner's position. For geometry, distinguish drawing, construction permissions, and proof. Honor an explicit request for a worked answer and record assistance.
5. Ask for an explanation in the learner's own words and a dated 2–4 sentence reflection at a natural stopping point. Invite a thesis connection without inventing one or changing thesis candidates without direction.
6. Save actual attempts, assistance, feedback, and next task in `learner-work.md`; save only learner-authored reflection in `reflection.md`. Apply the shared completion gate before checking any work. A passage-level session does not complete a book.

Session phases are flexible planning aids, not claims about elapsed time. For an unaided assessment, state the task/conditions, wait without coaching, and grade afterward. Do not deliver the entire session before the learner has responded.
